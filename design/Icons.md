# Icons Taxonomy - JB³ GameHub

All icons in JB³ GameHub use `lucide-react` for visual consistency and minimal footprint.

## Feature to Icon Mapping

| Module / Feature | Lucide Icon Component | Usage Context |
| :--- | :--- | :--- |
| **Brand Logo** | `Gamepad2` / `Terminal` | Main header app icon |
| **Dashboard** | `LayoutDashboard` / `Activity` | Sidebar main navigation item |
| **Server Manager** | `Server` / `HardDrive` | Server instance list & management |
| **World Library** | `Globe` / `Compass` | World dimensions & snapshots |
| **Plugin Store** | `Puzzle` / `Layers` | Plugins, extensions, and Geyser bridge |
| **Telemetry / Console** | `Activity` / `Terminal` | TPS graphs and RCON terminal logs |
| **AI Copilot** | `Bot` / `Sparkles` | Gemini 3.6 Flash AI Assistant |
| **Parent Mode / Security** | `ShieldCheck` / `Lock` | Screen time, whitelists, parent portal |
| **Education Portal** | `GraduationCap` / `BookOpen` | Classroom worlds & STEM challenges |
| **Backups & Snapshots** | `Database` / `Save` | Snapshot creation & cloud sync |
| **Power Actions** | `Play`, `Square`, `RotateCw` | Start, Stop, and Restart server controls |
| **Player Management** | `Users` / `UserCheck` | Active player lists and OP privileges |
| **Bedrock Crossplay** | `Smartphone` / `Radio` | Geyser & Floodgate crossplay indicators |
