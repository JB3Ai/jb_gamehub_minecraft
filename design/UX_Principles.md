# UX Principles - JB³ GameHub

## Core UX Directives

1. **Zero Technical Friction**:
   Users should never need to open a terminal, edit raw XML/YAML/JSON, or configure router port forwarding to host a server for their family or community.

2. **If a feature requires reading documentation, the UI has failed**:
   All workflows must feature intuitive visual cues, progressive disclosure, and pre-configured sensible defaults.

3. **If a task needs terminal commands, AI should perform them**:
   The JB AI Copilot converts natural language prompts like *"Fix server lag"* or *"Install EssentialsX and Geyser"* into direct RCON commands and configuration edits automatically.

4. **High Visual Scannability**:
   Use color-coded status badges (🟢 Emerald Online, 🔴 Rose Offline, 🟡 Amber Updating), high-contrast telemetry numbers, and live graphs so administrators can assess server health in under 2 seconds.

5. **Parent & Educator Friendly**:
   Clear visual indicators for screen-time limits, whitelist management, and 1-click snapshot backups allow non-technical guardians to manage Minecraft environments confidently.
