# ROADMAP.md - JB³ GameHub Feature Roadmap

## Phase 1: MVP Control Panel & AI Assistant (Current)
- [x] Bento Grid dashboard layout with live metrics (TPS, CPU, RAM, Players)
- [x] Multi-server switcher & deployment wizard
- [x] AI Copilot (Gemini 3.6 Flash) for natural language RCON execution
- [x] World Library & Plugin Store view interfaces
- [x] Live interactive RCON terminal stream & telemetry graphs

- [ ] Automated entity & chunk culling triggers when TPS drops below 18.0
- [ ] Scheduled night-time server snapshot backups & S3 cloud sync
- [ ] Discord webhook notification integration for server startup & player joins

## Phase 3: Multi-Node Distributed Cluster (Q4 2026)
- [ ] Docker / Kubernetes node daemon agent (`gamehub-daemon`)
- [ ] Support for BungeeCord & Velocity proxy networks
- [ ] Modpack installer for CurseForge & Modrinth
